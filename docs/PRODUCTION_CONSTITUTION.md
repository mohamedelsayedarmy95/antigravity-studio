# VeloraFrame Studio Production Constitution

1. Use the existing Client Brief, FilmSpec compiler, and Factory CLI for client production. Keep client media and approvals with the project or in private evidence storage. Preserve supported schemas, composition IDs, protected files, and work in progress.
2. Make camera movement purposeful and lighting physically coherent. Use spatial staging when depth helps communicate the idea. Use 2D, CSS, or SVG where it supports the shot and keeps product UI readable.
3. Show the product accurately. Choreograph movement, cuts, composition, and typography around the story. Choose brand-appropriate visual direction. Every effect earns its place.
4. Make text and product details readable at mobile scale in each delivered ratio. Use sound to reinforce the story. Check sync, clarity, and listening comfort for the intended output.
5. Record reproducible technical evidence, protect source media, and use the declared profile. Record licensing and privacy evidence before client work. Independent clearance and publication permission require their own decisions.
6. **Technical PASS never automatically means Creative PASS.** Only the human owner or director can approve creative quality. A render or green test supplies technical evidence.

Use the [Acceptance Gates](CREATIVE_ACCEPTANCE_GATES.md) for commands and evidence, the [Cinematic Quality Standard](CINEMATIC_QUALITY_STANDARD.md) for human review, and the [Capability Catalog](ENGINE_CAPABILITY_CATALOG.md) for supported techniques. The [architecture](ARCHITECTURE.md) owns engine boundaries and compatibility.

These instructions apply within this repository. Sibling production directories do not automatically inherit them.
